# BudgetBuddy: Student Expense Tracker CLI

## Description
BudgetBuddy is a CLI-based application that helps students track expenses, manage budgets, and analyze spending habits.

## Features
- Add expenses
- View expenses
- Search expenses
- Sort expenses
- Delete expenses
- Monthly summary
- JSON file storage

## Installation
1. Clone the repository
2. Open terminal
3. Run:

python src/main.py

## Technologies Used
- Python
- JSON

## Advanced Python Concept
- List comprehensions
- Lambda functions
- Context managers
